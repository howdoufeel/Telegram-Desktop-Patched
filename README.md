# Telegram Desktop Patched

Неофициальная версия Telegram Desktop с опцией **«Добавлять расшифровки голосовых»** в окне экспорта истории.

Репозиторий содержит полное дерево исходников Telegram Desktop **v7.2.9** с уже применённой доработкой. Исходная версия: [`fb2e33209517e1a34637d837bfadb3783f2fd59c`](https://github.com/telegramdesktop/tdesktop/commit/fb2e33209517e1a34637d837bfadb3783f2fd59c). Сведения о происхождении кода сохранены в [UPSTREAM.json](UPSTREAM.json), оригинальный README — в [README.upstream.md](README.upstream.md).

## Что добавлено

- Флажок «Добавлять расшифровки голосовых», по умолчанию выключенный; выбор сохраняется в настройках аккаунта.
- Получение текстов выбранных голосовых через Telegram API текущего аккаунта и сохранение в JSON и HTML.
- Отдельное поле `voice_transcription` в JSON со статусом, текстом, ошибкой и ID расшифровки.
- Последовательная обработка, ожидание ограничений Telegram, повторные попытки, отмена и итоговые счётчики.

Скачивание аудиофайлов включается отдельно. Доступность расшифровок, квоты и ограничения определяет Telegram; для массовой обработки предполагается Premium. Поддержаны обычные голосовые сообщения. Подробности формата, ограничений и тестов: [описание доработки](patches/README.md).

## Получить исходники

В отдельной папке для сборки:

```sh
git clone --recurse-submodules https://github.com/howdoufeel/Telegram-Desktop-Patched.git tdesktop
cd tdesktop
```

Если репозиторий уже клонирован без зависимостей:

```sh
git submodule update --init --recursive
```

Штатные подмодули Telegram сохранены с исходными фиксациями версий. Патч уже применён к файлам проекта. Его отдельная копия доступна в [patches/telegram-desktop-voice-transcriptions.patch](patches/telegram-desktop-voice-transcriptions.patch).

## Сборка

Используйте инструкции из этой версии исходников: [macOS](docs/building-mac.md), [Windows](docs/building-win.md), [Linux](docs/building-linux.md). Шаг клонирования в них заменяется командой выше; дальнейшая подготовка зависимостей выполняется для этой копии проекта. Нужны собственные [API-реквизиты Telegram](docs/api_credentials.md).

После подготовки и настройки дерева сборки:

```sh
cmake --build out --config Debug --target Telegram
```

Полная сборка, запуск изменённого клиента и реальный экспорт с Premium пока не проверены. Готовые установщики в репозиторий не включены.

## Проверка доработки

Из корня репозитория:

```sh
python3 Telegram/Tests/export_transcriptions/run.py
```

Нужны Python 3 и компилятор C++20 (`clang++` по умолчанию). Изолированные тесты компилируют реальные методы очереди с тестовыми адаптерами и проверяют политику повторов и 13 сценариев. Они не обращаются к аккаунту Telegram и не заменяют полную сборку клиента.
