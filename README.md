# Telegram Desktop Patched

Неофициальная версия Telegram Desktop с опцией **«Добавлять расшифровки голосовых»** в окне экспорта истории.

Репозиторий содержит полное дерево исходников Telegram Desktop **v7.2.9** с уже применённой доработкой. Исходная версия: [`fb2e33209517e1a34637d837bfadb3783f2fd59c`](https://github.com/telegramdesktop/tdesktop/commit/fb2e33209517e1a34637d837bfadb3783f2fd59c). Сведения о происхождении кода сохранены в [UPSTREAM.json](UPSTREAM.json), оригинальный README — в [README.upstream.md](README.upstream.md).

## Что добавлено

- Флажок «Добавлять расшифровки голосовых», по умолчанию выключенный; выбор сохраняется в настройках аккаунта.
- Получение текстов выбранных голосовых через Telegram API текущего аккаунта и сохранение в JSON и HTML.
- Отдельное поле `voice_transcription` в JSON со статусом, текстом, ошибкой и ID расшифровки.
- Последовательная обработка, ожидание ограничений Telegram, повторные попытки, отмена и итоговые счётчики.
- На macOS собирается отдельное приложение «Telegram Desktop Patched», которое устанавливается рядом с обычным Telegram Desktop и не затрагивает его.

Скачивание аудиофайлов включается отдельно. Доступность расшифровок, квоты и ограничения определяет Telegram; для массовой обработки предполагается Premium. Поддержаны обычные голосовые сообщения. Подробности формата, ограничений и тестов: [описание доработки](patches/README.md).

## Получить исходники

В отдельной папке для сборки:

```sh
git clone --recurse-submodules https://github.com/howdoufeel/Telegram-Desktop-Patched.git tdesktop
cd tdesktop
```

Если репозиторий уже клонирован без зависимостей:

```sh
git submodule update --init --recursive
```

Штатные подмодули Telegram сохранены с исходными фиксациями версий. Патч уже применён к файлам проекта. Его отдельная копия доступна в [patches/telegram-desktop-voice-transcriptions.patch](patches/telegram-desktop-voice-transcriptions.patch).

## Сборка

Используйте инструкции из этой версии исходников: [macOS](docs/building-mac.md), [Windows](docs/building-win.md), [Linux](docs/building-linux.md). Шаг клонирования в них заменяется командой выше; дальнейшая подготовка зависимостей выполняется для этой копии проекта. Нужны собственные [API-реквизиты Telegram](docs/api_credentials.md).

После подготовки и настройки дерева сборки:

```sh
cmake --build out --config Debug --target Telegram
```

Полная сборка, запуск изменённого клиента и реальный экспорт с Premium пока не проверены. Готовые установщики в репозиторий не включены.

## Готовая сборка для macOS

Сборка [MacOS Patched App](.github/workflows/mac_patched_app.yml) на GitHub Actions выдаёт универсальный `.dmg` для Mac на Apple Silicon и Intel. Сначала собираются библиотеки. Это несколько часов, поэтому работа идёт до трёх проходов, и каждый продолжает с места, где остановился предыдущий. Готовые библиотеки сохраняются в кеше, и следующие сборки идут быстрее. Сборка запускается при изменении исходников приложения или файла сборки, при пуше тега `mac-v*`, а после слияния в `main` — ещё и вручную на вкладке Actions.

Перед сборкой добавьте свои API-реквизиты:

1. На [my.telegram.org](https://my.telegram.org) войдите по номеру телефона, откройте «API development tools» и создайте приложение.
2. В репозитории откройте Settings → Secrets and variables → Actions и добавьте секреты `TDESKTOP_API_ID` и `TDESKTOP_API_HASH`.
3. Если сборка уже завершилась ошибкой «Add the TDESKTOP_API_ID…», нажмите в ней «Re-run failed jobs».

Готовый файл появится в разделе Artifacts запуска сборки и хранится 14 дней. Откройте `.dmg`, перетащите приложение в «Программы» и один раз выполните в Терминале:

```sh
xattr -dr com.apple.quarantine "/Applications/Telegram Desktop Patched.app"
```

Приложение подписано только локальной подписью без сертификата Apple, поэтому без этой команды macOS откажется его открыть. API-реквизиты встроены в приложение, а артефакты публичного репозитория может скачать любой пользователь GitHub. Не публикуйте ссылку на файл.

## Установка на macOS рядом с обычным Telegram Desktop

На macOS получается отдельное приложение `Telegram Desktop Patched.app` с собственным идентификатором `io.github.howdoufeel.TelegramDesktopPatched`. У Debug-сборки из Xcode к идентификатору добавляется `Debug`. Обычный Telegram Desktop при этом не меняется:

- данные Release-сборки хранятся в `~/Library/Application Support/Telegram Desktop Patched/`, отдельно от `~/Library/Application Support/Telegram Desktop/`, поэтому вход, настройки и кеш не пересекаются, а оба приложения можно запускать одновременно;
- ссылки `tg://` и `tonsite://` приложение не регистрирует, они по-прежнему открываются в обычном Telegram;
- уведомления и разрешения на микрофон и камеру macOS ведёт для каждого приложения отдельно;
- автообновление отключено. Официальное обновление заменило бы приложение и удалило бы доработку, поэтому настройка сборки с `-D DESKTOP_APP_DISABLE_AUTOUPDATE=OFF` останавливается с ошибкой. Новую версию Telegram можно получить только пересборкой с перенесённой доработкой.

Для постоянного использования соберите Release:

```sh
cmake --build out --config Release --target Telegram
```

Затем перенесите `out/Release/Telegram Desktop Patched.app` в «Программы». Debug-сборка работает медленнее и хранит данные в папке, где лежит `.app`, поэтому подходит только для проверки.

При первом запуске нужно войти в аккаунт, например по QR-коду с телефона. Приложение появится в списке устройств как отдельный сеанс. Общей с обычным Telegram остаётся только папка загрузок по умолчанию `~/Downloads/Telegram Desktop`, её можно сменить в настройках.

У приложения свой значок: оранжевый вместо синего, с бейджем звуковой волны. На размерах 16 и 32 px бейдж не рисуется, чтобы значок оставался чётким. Тот же вариант используется для настройки круглого значка. Значки строятся из оригинальных скриптом, которому нужны Pillow и NumPy:

```sh
python3 tools/patched_icon.py
```

Цвет фона меняется параметром `--hue` в градусах, по умолчанию 24.

## Проверка доработки

Из корня репозитория:

```sh
python3 Telegram/Tests/export_transcriptions/run.py
```

Нужны Python 3 и компилятор C++20 (`clang++` по умолчанию). Изолированные тесты компилируют реальные методы очереди с тестовыми адаптерами и проверяют политику повторов и 13 сценариев. Они не обращаются к аккаунту Telegram и не заменяют полную сборку клиента.
